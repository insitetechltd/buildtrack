# Documentation History

This folder contains historical, incident-specific, and superseded Markdown files retained for reference.

These files are not canonical. If they conflict with code or with current docs in `documentation/`, trust the code and the canonical docs.

## Structure

- `analysis/` - Investigations and superseded architectural or role-model analysis docs
- `incidents/` - One-off fixes, regressions, and resolved troubleshooting notes
- `releases/` - Point-in-time migration, release, and status snapshots
- `superseded/` - Replaced runbooks and duplicate operational guides

## Usage

- Use this folder for auditability and institutional memory.
- Do not treat these files as the current source of truth.
- Promote distilled learnings back into `documentation/` if they become durable guidance.
