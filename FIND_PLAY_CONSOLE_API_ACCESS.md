# How to Find Play Console API Access

The API access section can be tricky to find. Here are multiple ways to locate it.

## Method 1: Direct URL (Easiest)

**Direct link to API Access:**
```
https://play.google.com/console/u/0/developers/~/api-access
```

Just paste this URL in your browser while logged in as **insite.tech.ltd@gmail.com**

## Method 2: Through Setup Menu

1. Go to: https://play.google.com/console
2. Sign in with: **insite.tech.ltd@gmail.com**
3. Look for **Setup** in the left sidebar (gear icon ⚙️)
4. Click **Setup**
5. Look for **API access** in the submenu
   - It might be under "API access" or "Users and permissions"

## Method 3: Through Users and Permissions

1. Go to: https://play.google.com/console
2. In left sidebar, look for:
   - **Users and permissions** OR
   - **Account** → **Users and permissions** OR
   - **Settings** → **Users and permissions**
3. Click on it
4. Look for **API access** tab or section

## Method 4: Search in Play Console

1. Go to: https://play.google.com/console
2. Use the search bar at the top (if available)
3. Search for: "API access" or "service account"

## Method 5: Through App Settings

1. Go to: https://play.google.com/console
2. Select your app: **Taskr** (if you have one created)
3. In the app's left sidebar, look for:
   - **Setup** → **API access**
   - **Settings** → **API access**

## What You're Looking For

Once you find it, you should see:
- A page titled "API access" or "Users and permissions"
- A section called **"Service accounts"** or **"Linked service accounts"**
- A button that says **"Link service account"** or **"Grant access"**

## If You Still Can't Find It

### Option A: Check Your Account Type

Make sure you're logged in as the **account owner** (insite.tech.ltd@gmail.com), not a team member. Only account owners can access API settings.

### Option B: Try Different Navigation Paths

The exact location varies by account setup. Try these paths:

1. **Left sidebar** → **Setup** → **API access**
2. **Left sidebar** → **Account** → **API access**
3. **Left sidebar** → **Settings** → **API access**
4. **Left sidebar** → **Users and permissions** → **API access**
5. **Top menu** → **Account** → **API access**

### Option C: Use Direct Links

Try these direct links (replace with your account if needed):

- API Access: https://play.google.com/console/u/0/developers/~/api-access
- Users: https://play.google.com/console/u/0/developers/~/users
- Settings: https://play.google.com/console/u/0/developers/~/settings

## Alternative: Manual Upload (If API Access is Unavailable)

If you can't find API access or it's not available for your account, you can upload manually:

1. Go to: https://play.google.com/console
2. Select your app: **Taskr**
3. Go to: **Release** → **Testing** → **Internal testing** (or **Production**)
4. Click: **Create new release**
5. Upload: `android/app/build/outputs/bundle/release/app-release.aab`

This doesn't require API access setup.
