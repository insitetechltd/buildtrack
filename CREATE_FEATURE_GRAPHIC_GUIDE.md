# Create Feature Graphic for Android Play Store

## Requirements

- **Size**: 1024 x 500 pixels
- **Format**: PNG (24-bit recommended)
- **File size**: Max 15 MB (but keep it optimized, ideally under 1 MB)
- **Aspect ratio**: 2.048:1 (wide banner)

## What is a Feature Graphic?

The feature graphic appears at the top of your Play Store listing and is one of the first things users see. It's displayed prominently on:
- Your app's Play Store page
- Search results
- Featured app sections
- Homepage banners

## Design Best Practices

### ✅ DO:

1. **Keep it Simple**
   - Focus on 1-2 main elements
   - Avoid clutter
   - Make it readable at small sizes

2. **Showcase Your App**
   - Include app icon/logo
   - Show key features or UI elements
   - Use brand colors from your app

3. **Use Text Sparingly**
   - App name is sufficient
   - Optional: short tagline (3-4 words max)
   - Keep text large and readable

4. **Test Readability**
   - Should be clear at thumbnail size
   - Test on mobile devices
   - High contrast for text

5. **Follow Safe Zones**
   - Important content in center 80%
   - Avoid edges (may be cropped on some devices)
   - Key elements: 200px from each side

### ❌ DON'T:

1. Include promotional text ("Free!", "Sale!")
2. Add contact information or URLs
3. Use too many colors or busy patterns
4. Include screenshots (those go separately)
5. Make it too dark (Play Store background is white)

## Step-by-Step Creation Process

### Using Canva (Recommended for Quick Creation)

1. **Create Account**
   - Go to canva.com
   - Sign up for free account

2. **Create Custom Design**
   - Click "Create a design"
   - Choose "Custom size"
   - Enter: Width 1024px, Height 500px
   - Click "Create new design"

3. **Design Elements**
   - Upload your app icon (`assets/icon-1024.png`)
   - Add app name: "Taskr"
   - Add tagline (optional): "Task Management Made Simple"
   - Choose background color/gradient
   - Arrange elements

4. **Download**
   - Click "Download" button
   - Select "PNG" format
   - Ensure resolution is high quality
   - Download

5. **Optimize (Optional)**
   - Use TinyPNG.com to compress if file is large
   - Maintain quality while reducing file size

### Using Figma (Free & Professional)

1. **Create Account**
   - Go to figma.com
   - Sign up (free)

2. **Create New File**
   - Click "New design file"
   - Create frame: 1024 x 500

3. **Design**
   - Import app icon
   - Add text layers for app name
   - Design layout
   - Use brand colors

4. **Export**
   - Select frame
   - Right-click → Export
   - Choose PNG, 2x resolution (2048 x 1000 for retina)
   - Or export at 1x (1024 x 500)

## Testing Your Graphic

Before submitting:

1. **View on Mobile**
   - Open graphic on your phone
   - Check if text is readable
   - Verify it looks good at small size

2. **Test Thumbnail**
   - Resize to 512 x 250 (50%)
   - Ensure still readable

3. **Check Contrast**
   - Text should be clearly visible
   - Background shouldn't overpower content

4. **File Size**
   - Should be under 1 MB ideally
   - Compress if needed (TinyPNG.com)

## Troubleshooting

### Common Issues:

**Graphic appears blurry:**
- Export at 2x resolution (2048 x 1000)
- Or ensure original is crisp 1024 x 500

**File too large:**
- Compress at TinyPNG.com
- Reduce image complexity
- Optimize PNG

**Wrong size:**
- Double-check dimensions: 1024 x 500
- Some tools may default to different size
- Always verify before export

**Rejected by Play Store:**
- Ensure no promotional text
- No URLs or contact info
- Follow Play Store policies
- Keep it simple and professional
