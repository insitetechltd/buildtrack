# Quick Start: Reset Data for Testing

## 🚀 Fast Track - Reset Everything

Want to start fresh? Follow these 3 simple steps:

### Step 1: Open Developer Settings
```
Dashboard → Tap your avatar (top right) → Developer Settings
```

### Step 2: Clear All Data
1. Scroll to the **⚠️ Danger Zone** section (at the bottom)
2. Tap **"Clear All Local Data & Logout"**
3. Read the warning
4. Tap **"Clear & Logout"** to confirm

### Step 3: Login Again
1. The app will logout automatically
2. Login with your credentials
3. All data will be fresh from the database

**Done!** 🎉 You now have a clean slate for testing.

## 🎯 Common Tasks

### Just Want Fresh Data (Stay Logged In)
1. Developer Settings
2. Tap **"Force Sync All Data"**
3. Done!

### Tasks Acting Weird
1. Developer Settings
2. Tap **"Clear Task Cache"**
3. Tasks will refresh automatically

### Complete Fresh Start
1. Developer Settings
2. **"Clear All Local Data & Logout"** (in Danger Zone)
3. Login again

---

## ⚠️ Important

- **Local Data Only**: This clears data on your device
- **Database Safe**: Your Supabase database is NOT affected
- **Re-downloads**: Data comes back when you login
- **Quick Process**: Takes only a few seconds

---

## 💡 Pro Tips

1. **Before Testing**: Clear all data for a clean start
2. **Between Tests**: Use Force Sync for quick refresh
3. **Debugging**: Use View Storage Keys to see what's cached
4. **Selective**: Clear only what you need (tasks, projects, users)
