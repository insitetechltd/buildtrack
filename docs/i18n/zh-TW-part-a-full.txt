# Chinese translation brief (Insite / Taskr mobile app) — PART A ONLY

You are translating UI copy for a construction jobsite task app (photo evidence → task → review).
Target: **Traditional Chinese (zh-TW)** — Taiwan/HK field tone, not Mainland marketing Chinese unless asked.

## Rules
1. Output format (one line per entry, exactly):
   KEY | 繁體中文譯文
   Example: auth.login | 登入
2. Keep placeholders EXACTLY as in EN (do not translate brace names):
   {creatorName}, {assigneesList}, {arg1}, {count}, {name}, etc.
3. Keep emoji if present in EN.
4. Preferred glossary:
   - task → 工作 (or 任務 if already established in key context)
   - project → 專案
   - assign → 指派 / 分配
   - review / approval → 審核 / 審批
   - overdue → 逾期
   - progress → 進度
   - attachment / photo → 附件 / 相片
5. Do NOT translate brand/product names: Taskr, Insite, BuildTrack.
6. Do NOT invent new keys. Translate only the keys listed below.
7. Return ONLY the KEY | 譯文 lines (no numbering, no EN reprint, no commentary).
